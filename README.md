# OmniLocal Edge AI Platform

一个纯 HTML 的本地 AI 平台，双击就能跑，零配置，不用填 API Key。

## 先试再下（推荐）
不想配环境？先打开这个链接体验：

👉 **https://gfexbo.kicp.fun/**

> 首次加载需下载模型（几百 MB～几 GB），之后走浏览器缓存可离线使用。
> 试完觉得行，再回来下载这个 HTML 文件自己跑。

⚠️ 注意：在线 Demo 为演示用，随时可能关闭。想长期用请下载 HTML 到本地。

## 核心特点
- 纯 HTML 单文件，无依赖，免安装
- 双击直接在浏览器运行
- 零配置，不需要申请任何密钥
- 支持 WebGPU 原生推理
- 跨平台，100% 离线可用
- MIT 开源协议

## 它能干什么
- 💬 聊天：WebGPU 浏览器内推理，支持 Qwen / Llama / Phi / Gemma / SmolLM 等
- 🧮 JS 计算：沙箱内执行 JavaScript，数学、数据处理、编码转换
- 🎮 HTML 应用：生成完整 HTML 页面在沙箱运行，做小工具、小游戏、图表
- 🔍 联网搜索：维基百科 + DuckDuckGo，获取最新信息
- 📄 读本地文档：上传 txt / md / csv / json / pdf 等，直接问内容
- 📥 文件下载：生成文件并触发下载
- 🔊 语音朗读：回复自动朗读
- 🧠 长期记忆：记住你的偏好，刷新不丢

## 怎么用
1. 下载仓库里的 `omni-local-ai.html` 文件。
2. 双击用现代浏览器（如 Chrome/Edge）打开。
   ⚠️ 打开后需点「加载模型」，首次会下载模型文件，请耐心等待几分钟。
3. 直接输入内容开始对话，无需任何额外配置。

## 硬件参考
- 8G 内存：选 1.5B～3B 模型
- 16G 内存：选 3B～7B 模型
- 显存不足：换更小的模型

## 为什么这么做（设计决策）
这一节写给想学、想抄、想改的人看——代码是结果，选择才是重点。

- **为什么单文件？** 用户不应该为了用一个工具而装一个生态。
- **为什么 WebGPU？** 浏览器内跑真实模型，WASM 性能天花板太低。
- **为什么工具循环最多 6 轮？** 防止小模型死循环，也防止用户等太久。
- **为什么 IndexedDB 存文档？** localStorage 放不下大文件。
- **为什么 MIT 许可证？** 让想学的人放心学，想抄的人光明正大地抄——但署名权归我。
- **为什么 48KB 刚好？** 多一行是累赘，少一行是残缺。极简不是目标，是结果。

## 诚实边界
- 浏览器沙箱内无法删除/修改你磁盘上的文件，无法执行系统命令
- 本地小模型能力弱于云端大模型，复杂任务建议分步提问
- 部分功能依赖公开 CORS 代理，可能被拦截（非程序问题）

## 注意事项
首次打开会加载本地模型，稍等片刻。建议使用支持 WebGPU 的浏览器，断网也能用。
